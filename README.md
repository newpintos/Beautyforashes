# Beauty for Ashes Counselling Portfolio

This is a responsive portfolio website designed for a professional counsellor profile, built with Next.js, Shadcn UI, and Tailwind CSS.

## Getting Started

1.  Navigate to the project directory:
    ```bash
    cd portfolio
    ```

2.  Run the development server:
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Design System

The project uses a custom color palette defined in `src/app/globals.css`:
- **Primary:** `#B7BF8C` (Olive Green)
- **Secondary:** `#DADFC5` (Light Sage)
- **Accent:** `#F38458` (Orange)

## Components

Components are located in `src/components`:
- **Layout:** Header, Footer
- **Profile:** Hero, About, Approach, Qualifications, Expertise, Therapies, Fees, Availability, VisualBreak
